# InsightGPT - AI Business Intelligence Copilot

## Overview

InsightGPT is an AI-powered Business Intelligence Copilot that enables business users to ask questions in natural language and receive data-driven insights, SQL-powered analytics, visualizations, forecasts, and business recommendations.

## Tech Stack

- PostgreSQL
- Python
- FastAPI
- Streamlit
- LangChain
- Gemini API
- Power BI
- Scikit-Learn
